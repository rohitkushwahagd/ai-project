# First measured local baseline: 22 September 2026

This is an eight-document, ten-question **synthetic development experiment**, not a held-out or enterprise-scale benchmark. [Frozen machine-readable report](2026-09-22-baseline.json).

## Conditions

- Intel Core i5-10300H, 8 GB host RAM, local Docker CPU inference.
- One sequential evaluation round, concurrency 1. Quality queries bypassed the response cache; embedding/model caches may be warm.
- Local chat configuration: `qwen2.5:1.5b`; embedding configuration: `nomic-embed-text:v1.5`.
- Judge disabled. Faithfulness was **not measured** and no human review score is claimed.
- Separate cache comparison: three observed miss/hit pairs.

## Observed results

| Measure | Result |
|---|---:|
| Completed questions | 10 / 10 |
| Configured development gates | Passed |
| Source-level precision@5, fixed denominator | 0.2222 |
| Source-level recall@5 on answerable cases | 1.0000 |
| Expected-fact lexical coverage | 1.0000 |
| Abstention phrase matching | 1.0000 |
| Median full-answer latency | 9.746 s |
| Sample p95 / slowest full answer | 116.309 s |
| Sample p95 first-token latency | 114.776 s |
| Mean input / output tokens | 396.2 / 21.9 |
| External hosted-model invoice | $0, local Ollama |
| Hardware/electricity cost | Unmeasured |

Question q1 took 116.309 seconds, mostly before its first token. Other questions took approximately 8.6–12.4 seconds. This shows a first-token delay requiring profiling; this run alone does not establish its cause. With only ten observations, nearest-rank p95 and p99 both select the maximum. They are not robust tail-latency estimates.

Precision uses relevant **source IDs**, deduplicated among top-five chunks, divided by five. For a question with one relevant source, its maximum is 0.20. It cannot be compared directly with a chunk-level metric or the playbook's sample 0.87 number. Recall 1.0 and lexical fact matching 1.0 do not establish semantic correctness, citation validity, or resistance to prompt injection.

The three cache-hit client latencies were 2.124, 2.072, and 3.841 seconds. Mean pairwise client-latency reduction was approximately 49%; this is a tiny local timing sample, **not a measured token-cost or business-cost reduction**. Investigate the remaining cached-request latency before making a performance claim.
